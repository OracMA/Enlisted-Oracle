# Enlisted Oracle

Десктопное приложение для анализа игроков Enlisted.
Распознаёт ники со скриншота, ищет их в базе (~687 000 игроков)
и показывает статистику + сравнение команд.

## Установка
0. РАСПАКУЙ АХРИВ ENLISTEDPLAYERFULL В КОРНЕВУЮ ПАПКУ РЯДОМ С GUI.PY И MAIN.PY
1. Установи Python 3.10+ — https://www.python.org/downloads/
   ⚠️ При установке поставь галочку **"Add Python to PATH"**.

2. Двойной клик по `install.bat` — доустановит все библиотеки.
3. Двойной клик по `run.bat` — запустит программу.

Готово. Ярлык можно вынести на рабочий стол.

## Возможности

- 📸 **Сканировать** — Shift+Win+S выделить ТОЛЬКО область с никами,
  потом кнопка «Сканировать». Программа распознает текст и найдёт игроков.
- ✏️ **Ручной ввод** — ввод ников вручную, если скриншота нет.
- ⚖️ **Сравнить** — сравнение двух последних команд с вердиктом.
- 🧹 **Очистить команды** — сбросить буфер.

## Цветовая шкала

🟢 слабый  |  🟡 ниже среднего  |  🔶 средний  |  🔻 сильный  |  🟣 элита

Пороги для каждой метрики (K/D, WR, ELO, хедшоты, захваты, БТР,
техника, постройки) считались по перцентилям всей базы.





## Если что-то не работает

- **Не запускается `install.bat`** — Python не установлен или не в PATH.
  Переустанови Python с галочкой «Add to PATH».
- **Не открывается GUI после `install.bat`** — запусти `run.bat`,
  он покажет текст ошибки в консоли.
- **Скан не находит ников** — проверь, что на скриншоте видно
  ники целиком, без обрезки; 
- **База не загрузилась** — убедись, что `enlisted_players_full.csv`
  лежит рядом с `main.py`.

## Технические детали

- Python 3.10+
- PyQt6 для интерфейса
- Загрузка базы: ~5 сек, ~300 МБ RAM

🌐 Смена языка
Если ты случайно выбрал не тот язык при первом запуске, это легко исправить:

Открой файл user_stats.json в папке с программой.

Найди строку "lang": "ru" (или "lang": "en").

Поменяй на нужный: "lang": "ru" — русский, "lang": "en" — английский.

Сохрани файл и перезапусти программу.

Либо просто удали user_stats.json — при следующем запуске снова появится окно выбора языка.
