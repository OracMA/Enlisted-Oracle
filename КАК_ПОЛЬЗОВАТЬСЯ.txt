### 📸 КАК ПОЛЬЗОВАТЬСЯ

**1.** Сделай скриншот **ТОЛЬКО с никами команды А** — с 1 по 10 место.  
Горячие клавиши: **`SHIFT + WIN + S`** → выдели область → скриншот автоматически попадёт в буфер.
1.2 Нажать кнопку сканировать

**2.** Сделай скриншот команды Б **аналогично** (**`SHIFT + WIN + S`**).
2.2 Нажать кнопку сканировать
**3.** Нажми кнопку **`⚖️ Сравнить`**.

**4.** Готово — таблица сравнения появится внизу окна.  
Нажми **`📋 Скопировать в буфер`**, чтобы сохранить скриншот результата для отправки 

---

### ⚙️ КНОПКИ

| Кнопка | Что делает |
|---|---|
| **📸 Сканировать** | Распознаёт последний скриншот из буфера и добавляет команду |
| **✏️ Ручной ввод** | Ввести ники вручную (если OCR ошибся) |
| **⚖️ Сравнить** | Сравнивает две последние команды |
| **🧹 Очистить команды** | Сбрасывает буфер команд |
| **📋 Показать лог** | Показывает подробный лог анализа |
| **🔊 / 🔇** | Включить/выключить звук |
| **📋 Скопировать в буфер** | Копирует результат для отправки |

### ⚠️ ВАЖНО

- Скриншот должен содержать **только ники** (без лишних панелей, кнопок, чата).
- Если OCR ошибся — используй **`✏️ Ручной ввод`**.
- Если Windows Defender ругается на `.exe` — это **ложное срабатывание**, нажми «Подробнее» → «Выполнить в любом случае».
